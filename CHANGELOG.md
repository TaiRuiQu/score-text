# Changelog

## 0.1.0 — 2026-11-06

First public release.

- Agent-friendly YAML score notation with compact or explicit note events.
- Numbered notation with lyrics, guitar TAB and strumming, piano grand staff,
  pitched staves and percussion, with independent voices.
- Changing meter and key, dotted and tuplet durations, ties, slurs, tempo changes
  and linear accelerando/ritardando.
- Shared score layout and PDF, SVG, PNG, printable HTML, MIDI and MusicXML exports.
- Offline bundled fonts, JSON Schema, stdin support and structured CLI diagnostics.
- Four runnable examples, including a C-major Ode to Joy theme and a mixed ensemble.

Known limits and export behavior are documented in the README and notation guide.
